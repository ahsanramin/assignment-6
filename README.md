# Digital Tools Buying Website

A fully responsive e‑commerce interface built with **React (Vite)**, **Tailwind CSS**, and **React Toastify**. Users can browse premium digital tools, add them to a cart, remove items, and proceed to checkout.

## Live Demo
[Link to your deployed site]

## Technologies
- React (Vite)
- Tailwind CSS
- React Toastify
- JavaScript (ES6+)
- JSON

## Features
1. **Product Listing** – 6 premium digital tools with details, tags, and features.
2. **Cart Management** – Add/remove items, view total price, and clear cart.
3. **Toast Notifications** – Real‑time alerts for all cart actions.
4. **Responsive Design** – Works on desktop, tablet, and mobile.
5. **Mobile Menu** – Hamburger menu for small screens.

## Installation
1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:5173`.
